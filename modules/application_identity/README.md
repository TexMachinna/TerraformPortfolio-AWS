# Application_identity module

## Overview

This modules creates and configures the requried IAM roles for the EC2 instances (generated by the compue module)
to be able to connect to the designated DynamoDB message table.

It creates:
- AWS IAM Role
- AWS IAM Policy
- AWS IAM Role Polocy attachment

## Usage

```text
module "application_identity" {
  source = "../../modules/application_identity"

  project_name    = var.project_name
  environment_tag = var.environment_tag

  dynamodb_table_arn = module.dynamodb.table_arn
}
```

## Inputs

| Name                  | Description                                                 | Type          | Required |
| --------------------- | ----------------------------------------------------------- | ------------- | -------- |
| `project_name`        | Project name used in IAM resource names                     | `string`      | yes      |
| `dynamodb_table_arn`  | ARN of the DynamoDB Table the EC2 application may access    | `string`      | yes      |
| `environment_tag`     | Tags applied to module resources                            | `string`      | yes      |

## Outputs

| Name                    | Description                                                     |
| ----------------------- | --------------------------------------------------------------- |
| `instance_profile_name` | "Name of the IAM instance profile for the application instances |
| `instance_profile_arn`  | ARN of the IAM instance profile                                 |
| `role_name`             | Name of the application EC2 IAM role                            |
| `role_arn`              | ARN of the application EC2 IAM role                             |
| `policy_arn`            | ARN of the DynamoDB access policy                               |
